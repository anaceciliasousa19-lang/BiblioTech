## Objetivo do software

O BiblioTech é um sistema desktop desenvolvido para auxiliar no gerenciamento de uma biblioteca. O sistema tem como objetivo facilitar o cadastro e a consulta de livros e leitores, além de permitir o controle dos empréstimos e devoluções realizados.

O projeto utiliza banco de dados MySQL para armazenar as informações de forma persistente, permitindo que os registros continuem disponíveis após o encerramento do programa.

## Funcionalidades do sistema

- Login de acesso ao sistema
- Cadastro de livros
- Consulta e pesquisa do acervo
- Cadastro de leitores
- Consulta de leitores cadastrados
- Registro de empréstimos
- Registro de devoluções
- Controle de disponibilidade dos livros
- Consulta de empréstimos ativos e atrasados
- Dashboard com informações gerais do sistema
- Integração do Java com banco de dados MySQL por JDBC
- Persistência das informações no banco de dados

## Banco de dados

O sistema utiliza MySQL. O banco principal utilizado pelo projeto é `bibliotech` e o script SQL de criação e dados iniciais deve acompanhar o projeto.

## Execução do projeto

1. Criar o banco de dados utilizando o script SQL fornecido.
2. Configurar usuário e senha do MySQL no projeto.
3. Abrir o projeto no NetBeans.
4. Executar a aplicação.
5. Realizar o login no sistema.

## Versionamento

O projeto utiliza Git e GitHub para controle de versão. As alterações são registradas por meio de commits e sincronizadas com o repositório remoto por operações de push e pull.
